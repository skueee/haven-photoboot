## Why not Windows ?
The [CameraServer](https://docs.godotengine.org/en/stable/classes/class_cameraserver.html) Object is not available on Windows, and I don't think it's worth the hassle to find an alternative since WSL exists, and most Photoboots can run Linux (RasbPi...)
